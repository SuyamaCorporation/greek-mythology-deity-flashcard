# Greek Mythology Deity & Role Flashcard Deck

A 20-card flashcard deck covering major Greek gods and goddesses with animated flip cards showing deity name on the front and domain, symbols, Roman counterpart, and notable facts on the back. Study mode includes shuffle, spaced-repetition scheduling (Hard/OK/Easy buttons set 1/3/7-day review intervals), and a "Due for Review" filter. Quiz mode presents domain and symbols as clues with four multiple-choice name options, and a Progress tab tracks mastery status per deity — all persisted via localStorage.
